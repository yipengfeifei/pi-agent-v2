# 婚礼策略框架 v1.0

> 上游：婚礼行业调研简报（一线城市 · 中档预算，as_of 2026-08-08）
> 下游可消费：预算表 → 预算追踪/采购节点；时间线 → 倒计时任务节点；主题 → 文案材料包回填与设计节点；风险表 → 执行监控节点

---

## 1. 目标与验收标准

**一句话目标**：在一线城市、宾客 200 人（≈20 桌）、总预算 40 万的前提下，把预算重心放在**宾客体验（婚宴）与记忆点（影像/仪式）**上，装饰从简、质感取胜，用 12 个月倒排完成一场"不超支、不踩坑、有记忆点"的中档婚礼。

**总验收标准**：
1. 总花费 ≤ 40 万（含机动金），且婚礼日 D 前 4 周（G2）机动金余额 ≥ 2 万；
2. 每个里程碑有可验证产出（合同/确认单/成片/回收率），见 §4 各 gate；
3. 日期未定 → 全部节点以婚礼日 W 倒排，任何节点可独立平移。

| 项 | 本节点取值 | 状态 |
|---|---|---|
| 预算 | 40 万 | 任务给定（默认假设） |
| 宾客 | 200 人 ≈ 20 桌 | 任务给定（默认假设） |
| 日期 | 未定，按 W 倒排 | 任务给定（默认假设） |
| 城市 | 一线城市（简报口径京沪深广） | **未确认**，价格随城市 ±50% → 须在 G1 询价时落定 |

| 风格偏好 | 暖调轻奢（见 §3） | **未确认**，W-10 前可由用户推翻 |

## 3. 主题定位与风格方向

**定位一句话**："把 40 万花在餐桌上和影像里，不花在装饰堆料上。"
依据：简报推算五星酒店 20 桌 ≈ 24–30 万会吃掉预算 60–75%（不可行）；北大光华研究显示婚宴在直接消费中占比超 50%（吻合本框架 50% 基准）。

**路线取舍（三选一，决策点 W-10）**：

| 路线 | 内容 | 预算特征 | 适用 |
|---|---|---|---|
| **S1 基准（推荐）** | 中高档酒店高配 / 五星入门档 + 轻布置（花艺为主） | 婚宴 18–22 万 + 婚庆 6 万 | 主流场景，质感与预算平衡 |
| **S2 省心替代** | 一站式婚礼堂全包（8 万起，免二次加价） | 总价约 25–32 万，机动金更厚 | G1 抢不到热门场地 / 时间压缩时启用 |
| **S3 宾客体验优先** | 压缩布置与乐队，婚宴上探至 55%（22 万） | 婚宴 22 万 | 用户明确"吃最重要" |

**风格方向（默认，可推翻）**：暖调轻奢——奶油/香槟色系 + 木质 + 花艺点缀，与酒店宴会厅兼容度高；备选「新中式雅致」，仅当选婚礼堂/文化场地时启用。**决策标准**：场地定稿（W-10）后由下游设计节点出 2 套视觉方案，用户选 1。

## 4. 预算分配框架（含机动金）

| 项目 | 占比 | 基准金额 | 弹性区间 | 备注 |
|---|---|---|---|---|
| 婚宴（含服务费） | 50% | 20.0 万 | 18–22 万 | ≈ 10,000 元/桌含服务费；覆盖四星高配或五星入门，谈判锚点：裸价 8,000–8,500 可谈 |
| 婚庆全案（策划+布置+统筹） | 15% | 6.0 万 | 4.8–7.2 万 | 简报中档区间 1.5–3 万起，此档偏中上；**隐形加价 20–40% 预期 1.2–2.4 万由机动金覆盖** |
| 四大金刚 | 7.5% | 3.0 万 | 2.4–3.6 万 | 摄影 0.6 / 摄像双机位 0.9 / 跟妆 0.5 / 司仪 0.6 / 预留 0.4 |
| 婚纱照 | 3% | 1.2 万 | 0.7–1.3 万 | 简报均价 6,800 元，1.2 万含加片余量 |
| 礼服（租赁） | 2.5% | 1.0 万 | 0.3–2.0 万 | 租赁区间 3 千–2 万 |
| 乐队 | 2.5% | 1.0 万 | 0–1.5 万 | 简报区间 5 千–2 万；**可砍项（P3）** |
| 杂项（请柬/喜糖/伴手礼/红包/小件） | 4.5% | 1.8 万 | 1.2–2.4 万 | 伴手礼 30 元×200 ≈ 0.6 万 |
| **机动金** | **15%** | **6.0 万** | **≥2 万保底** | 用途优先级见下 |
| **合计** | 100% | **40.0 万** | | |

**机动金规则**：
1. 用途优先级：① 婚庆落地加价（预期 1.2–2.4 万）→ ② 餐标/桌数波动 → ③ 吉日溢价 → ④ 影像升级；
2. 硬约束：G2（W-4）后余额 ≥ 2 万；单笔动用 > 1 万须用户确认（go/no-go）；
3. 结余处理：回退预算或升级影像（双机位→三机位/加时）。

**硬性约束**：酒店满 10 桌起订 + 保底桌数条款必须写进合同（人数波动风险，见 §5）；反食品浪费法要求适度备餐——菜单按"N 桌 + 备 1 桌浮动"签，不做超量加菜。

**依赖关系（文字 DAG）**：
- `婚期 → 酒店 → 桌数/餐标 → 预算快照 → 布置方案`
- `婚期 → 四大金刚档期`（"先定婚期再抢酒店金刚"为铁律，热门吉日需提前 1 年+）
- `名单初稿 → 请柬 → RSVP → 最终桌数 → 保底桌数校验 → 席位`
- `婚纱照 →（1–2 月后期）→ 成片`（供请柬/现场/快剪）
- `试菜 → 菜单定稿`；`彩排 ← 流程单 + 司仪 + 全供应商对表`

## 6. 风险与分支计划

| 风险 | 概率/影响 | 应对 | 触发点 |
|---|---|---|---|
| 热门吉日/周末场地档期抢不到（需提前 1 年+，溢价 10–20%） | 高/高 | 分支 A：改平日/周中（省 10–20%）；分支 B：转 S2 婚礼堂全包；分支 C：改期 | G1 失败 |
| 婚庆隐形加价 20–40%（花材/灯光追价） | 高/中 | 合同锁增项清单 + 机动金覆盖（预留 1.2–2.4 万） | 随时，G2 复核 |
| 宾客人数波动 ±10%（±2 桌） | 中/中 | 合同保底桌数条款 + 菜单备 1 桌浮动 | G3 |
| 2026 现行价格未核实（官方 2025 套餐已过期） | 高/中 | 现场询价列为 G1 前置硬性动作，桌面价不作签约依据 | G1 |
| 乐队报价为推断值（内地官方价目稀缺） | 中/低 | 早签约早锁定；P3 可整项砍掉 | G2 |
| 户外/特色场地天气与档期（仅 S 路线含户外时） | 中/高 | 合同含室内备场条款 + 天气预案 | G4 |

**降级顺序（预算紧张时依次执行）**：乐队（1.0 万）→ 伴手礼/杂项（≤0.6 万）→ 布置增项（≤1.5 万）→ 摄像双机位降单机位（0.3 万）。**婚宴与四大金刚不降级**（宾客体验与记忆点底线）。
